# 01 数学 · 技术方案

> 模块总览见 [程序化2D骨架姿态引擎_技术方案 .md](./程序化2D骨架姿态引擎_技术方案%20.md)。  
> 本文覆盖二维与三维向量、二维叉积与三维叉积、法向量、3×3 仿射变换和角度。骨骼、坐标系层次、像素和步态由后续模块规定。三维不引入 4×4 矩阵。

## 1. 职责

本模块是引擎的运算语言。它回答四件事：

- 二维向量怎么相加、求长、单位化，以及怎么取逆时针法向量
- 三维向量怎么做叉积，以及怎么从两条边或一个三角面得到单位法向量
- 一个 3×3 变换怎么组合、求逆、作用于一个点或一个方向
- 角度怎么换算、折回一个周期、取最短有符号差
- 这些结果写进调用者已经准备好的缓冲

它不解释这些数在角色身上的含义。朝向镜像、父子骨骼、米和像素的分工属于 02 及以后。

## 2. 库选型

热路径需要的是：列主序、9 个浮点数的矩阵、显式输出参数、不在运算时分配对象。按这个条件比较现成的库。

| 库 | 版本与许可 | 与本模块的关系 |
|---|---|---|
| [gl-matrix](https://github.com/toji/gl-matrix) | 3.4.4，MIT，npm 周下载量约 1.08×10⁷（截至 2026-10） | **采用。** `mat3` 是 `Float32Array(9)`，列主序，平移在索引 6 和 7，与 GLSL `mat3` 一致。函数形如 `fn(out, a, b)`，写出 `out` 并返回它。`fromRotation` 的正角把 `+X` 转到 `+Y`，即逆时针。包内自带 TypeScript 声明。 |
| [wgpu-matrix](https://github.com/greggman/wgpu-matrix) | MIT | 不采用。它的 `mat3` 按 WebGPU uniform 规则占 12 个浮点数。本引擎的矩阵要和 GLSL `mat3` 的 9 个数对齐，多出来的填充会让后续蒙皮和上传错位。 |
| [PixiJS `Matrix`](https://pixijs.download/v8.18.0/docs/maths.Matrix.html) | 随 PixiJS v8 | 不采用。它是带 `a, b, c, d, tx, ty` 字段的对象，运算返回 `this`。解算核心不能依赖渲染库。渲染绑定时再从本模块的 9 个数填进 Pixi 矩阵。 |
| [linearly](https://github.com/baku89/linearly) | MIT | 不采用。它故意做成不可变数组，每次运算返回新数组；角度参数用度。本模块内部用弧度，热路径不能为每次乘法分配矩阵。 |
| ml-matrix、mathjs、Three.js `Matrix3` | — | 不采用。前两个是通用线性代数，对象大、会分配；Three 的矩阵类型绑在三维引擎上。本模块的变换仍是 3×3 仿射。三维只增加向量、叉积和法向量。 |

### 2.1 采用方式

安装并锁定 `gl-matrix@3.4.4`。只有 `src/math/` 可以导入它。其余模块导入本模块的函数，不接触 `gl-matrix` 的 `mat3`、`vec2`、`vec3`、`mat4`、`quat`。

本模块是一层薄封装，原因有三条：

1. `vec2.transformMat3` 把第三分量当成 `1`，只能变换点。方向必须忽略平移，库里没有对应函数。
2. `mat3.invert` 在行列式为 0 时返回 `null`，并且上层需要一个明确的成败结果，而不是「失败时拿到空值」。
3. `mat3.create()` 会分配。热路径只接受调用者传入的 `out`。

禁止调用 `glMatrix.setMatrixArrayType`。库默认的 `Float32Array` 必须保持不变。也禁止使用 `mat3.projection`：那是像素空间的投影，不属于本模块。

`gl-matrix` 的 `multiply(out, a, b)` 计算的是 `out = a · b`。对列向量，右边的 `b` 先生效。`translate`、`rotate`、`scale` 都是把新变换右乘到已有矩阵上。封装保持这个顺序，不另起一套乘法方向。

## 3. 数据

```ts
export type Vec2 = Float32Array
export type Vec3 = Float32Array
export type Mat3 = Float32Array
```

`Vec2` 的长度是 2，`Vec3` 的长度是 3，`Mat3` 的长度是 9。类型本身不在运行时检查长度；创建函数和测试保证长度。调用者传入更短的数组属于调用错误。

矩阵按列主序存放。写成数学矩阵是：

```text
| m0  m3  m6 |
| m1  m4  m7 |
| m2  m5  m8 |
```

索引 6、7 是平移。索引 8 在仿射变换里是 `1`。正旋转矩阵是：

```text
|  cos θ  -sin θ   0 |
|  sin θ   cos θ   0 |
|  0       0       1 |
```

`θ = π/2` 时，点 `(1, 0)` 变为 `(0, 1)`。

点和方向都用 `Vec2` 存放，区别在作用函数：

| 函数 | 齐次分量 | 结果 |
|---|---|---|
| `transformPoint` | `1` | 受平移影响 |
| `transformVector` | `0` | 平移项不加入结果 |

## 5. 接口

所有会写出结果的函数都把 `out` 放在第一个参数，并返回同一个 `out`。`out` 可以和某个输入是同一块缓冲；实现按 `gl-matrix` 已处理的别名规则来写，方向变换和角度函数在重叠时先把输入读进局部变量。

创建函数只在初始化时使用。固定步、蒙皮和渲染求值里不调用它们。

### 5.1 二维向量

| 函数 | 行为 | 实现 |
|---|---|---|
| `createVec2()` | 返回 `(0, 0)` | `vec2.create` |
| `setVec2(out, x, y)` | 写入两个分量 | 直接写 |
| `copyVec2(out, a)` | 复制 | `vec2.copy` |
| `addVec2(out, a, b)` | `a + b` | `vec2.add` |
| `subVec2(out, a, b)` | `a - b` | `vec2.subtract` |
| `scaleVec2(out, a, s)` | 数乘 | `vec2.scale` |
| `negateVec2(out, a)` | 取反 | `vec2.negate` |
| `dotVec2(a, b)` | 点积 | `vec2.dot` |
| `crossVec2(a, b)` | 二维叉积 `ax·by − ay·bx`，结果是标量；`b` 在 `a` 逆时针一侧时为正 | 直接计算。不用 `vec2.cross`，那个函数把结果写成三维向量 |
| `normalVec2(out, a)` | `a` 的单位法向量，等于把 `a` 逆时针转 90° 后单位化，即 `(-ay, ax) / \|a\|`。长度为 0 时写入 `(0, 0)` 并返回 `false` | 直接计算 |
| `lengthVec2(a)` | 长度 | `vec2.length` |
| `squaredLengthVec2(a)` | 长度平方 | `vec2.squaredLength` |
| `distanceVec2(a, b)` | 距离 | `vec2.distance` |
| `normalizeVec2(out, a)` | 单位化；长度为 0 时写入 `(0, 0)` 并返回 `false` | 先判断长度，再 `vec2.normalize` |
| `lerpVec2(out, a, b, t)` | 线性插值，不限制 `t` | `vec2.lerp` |

`gl-matrix` 的 `vec2.normalize` 在长度为 0 时会得到非有限数。本模块先判断，零向量不调用它。`normalVec2` 同样先判断长度。`(1, 0)` 的法向量是 `(0, 1)`，与 `fromRotation(π/2)` 的方向相同。

### 5.2 三维向量

三维叉积遵守右手定则：`X × Y = Z`。法向量是单位化之后的叉积。计算用局部变量完成，不另分配缓冲。长度为 0 或两条边平行时写入 `(0, 0, 0)` 并返回 `false`。

| 函数 | 行为 | 实现 |
|---|---|---|
| `createVec3()` | 返回 `(0, 0, 0)` | `vec3.create` |
| `setVec3(out, x, y, z)` | 写入三个分量 | 直接写 |
| `copyVec3(out, a)` | 复制 | `vec3.copy` |
| `crossVec3(out, a, b)` | `a × b` | `vec3.cross` |
| `lengthVec3(a)` | 长度 | `vec3.length` |
| `normalizeVec3(out, a)` | 单位化；长度为 0 时写入 `(0, 0, 0)` 并返回 `false` | 先判断长度，再 `vec3.normalize` |
| `normalVec3(out, a, b)` | `a × b` 的单位向量 | 先把叉积写入局部变量，再单位化 |
| `faceNormalVec3(out, a, b, c)` | 三角面 `abc` 的单位法向量，即 `(b − a) × (c − a)` 再单位化。从法向量正向看去，三点是逆时针 | 边向量和叉积都写在局部变量里 |

`out` 可以与 `a`、`b` 或 `c` 是同一块缓冲。写 `out` 之前先把要用的分量读进局部变量。

### 5.3 矩阵

| 函数 | 行为 | 实现 |
|---|---|---|
| `createMat3()` | 单位矩阵 | `mat3.create` |
| `identityMat3(out)` | 写成单位矩阵 | `mat3.identity` |
| `copyMat3(out, a)` | 复制 9 个数 | `mat3.copy` |
| `multiplyMat3(out, a, b)` | `out = a · b` | `mat3.multiply` |
| `invertMat3(out, a)` | 成功写出逆矩阵并返回 `true`；行列式为 0 或任一元素非有限时返回 `false`，并且不改 `out` | 先查有限性和 `mat3.determinant`，通过后再 `mat3.invert` |
| `determinantMat3(a)` | 行列式 | `mat3.determinant` |
| `fromTranslation(out, v)` | 平移矩阵 | `mat3.fromTranslation` |
| `fromRotation(out, rad)` | 绕原点的旋转 | `mat3.fromRotation` |
| `fromScaling(out, v)` | 缩放矩阵，允许 `sx` 与 `sy` 不同，也允许负值 | `mat3.fromScaling` |
| `translateMat3(out, a, v)` | `out = a · T(v)` | `mat3.translate` |
| `rotateMat3(out, a, rad)` | `out = a · R(rad)` | `mat3.rotate` |
| `scaleMat3(out, a, v)` | `out = a · S(v)` | `mat3.scale` |
| `composeTRS(out, translation, rotationRad, scale)` | `out = T · R · S` | 本模块直接写 9 个数，不用中间矩阵 |
| `transformPoint(out, a, m)` | 点，第三分量为 1 | `vec2.transformMat3` |
| `transformVector(out, a, m)` | 方向，第三分量为 0 | 本模块写 `out0 = m0·x + m3·y`，`out1 = m1·x + m4·y` |

`composeTRS` 的展开是：

```text
c = cos(rotationRad), s = sin(rotationRad)
out = [c·sx, s·sx, 0,  -s·sy, c·sy, 0,  tx, ty, 1]
```

这与先做 `fromScaling`、再右乘旋转、再右乘平移的结果相同。测试用三条 `gl-matrix` 矩阵相乘对照。

骨骼是否允许非均匀缩放由上层决定。本模块保留一般缩放，因为反射可以表示成 `sx = -1, sy = 1` 的缩放。行列式的符号因此可以被上层读取。

### 5.4 角度

内部运算用弧度。

| 函数 | 行为 |
|---|---|
| `degToRad(deg)` | `deg · π / 180` |
| `radToDeg(rad)` | `rad · 180 / π` |
| `normalizeAngle(rad)` | 折到 `(-π, π]` |
| `angleDelta(from, to)` | `normalizeAngle(to - from)`，范围同样是 `(-π, π]` |

`normalizeAngle` 用一次除法和取余完成，不写循环。`±π` 都折到 `+π`。非有限输入原样返回，由调用方拒绝。

## 6. 验收

测试直接调用本模块，不把 `gl-matrix` 当被测接口。数值比较用绝对误差 `1e-6`，行列式和往返另加下面的用例。

1. 单位矩阵乘任意矩阵，两边结果相同。`multiplyMat3(out, a, b)` 与 `multiplyMat3(out, b, a)` 在平移加旋转时不同。
2. `fromRotation(π/2)` 作用在点 `(1, 0)` 上得到 `(0, 1)`。
3. 先平移 `(10, 0)` 再旋转 `π/2`，与先旋转再平移，得到的矩阵不同。`composeTRS` 等于 `T · R · S`。
4. 平移矩阵作用在点 `(1, 2)` 上带上平移；作用在方向 `(1, 2)` 上结果仍是 `(1, 2)`。
5. 可逆矩阵与自己的逆相乘，回到单位矩阵。行列式为 0 时 `invertMat3` 返回 `false`，`out` 保持调用前的内容。
6. `fromScaling((-1, 1))` 的行列式为 `-1`。点 `(1, 0)` 变为 `(-1, 0)`。
7. 零向量 `normalizeVec2` 返回 `false`，`out` 为 `(0, 0)`。`crossVec2((1, 0), (0, 1))` 为 `1`，交换顺序为 `-1`，平行向量为 `0`。`normalVec2(1, 0)` 为 `(0, 1)`；零向量返回 `false` 并写入 `(0, 0)`。
8. `crossVec3((1, 0, 0), (0, 1, 0))` 为 `(0, 0, 1)`，交换顺序为 `(0, 0, -1)`，平行向量为 `(0, 0, 0)`。`normalVec3` 得到同一方向的单位向量；平行时返回 `false` 并写入零向量。`faceNormalVec3` 对 `(0, 0, 0)`、`(1, 0, 0)`、`(0, 1, 0)` 得到 `(0, 0, 1)`；三点共线时同样失败。
9. `normalizeAngle` 把 `3π` 折到 `π`，把 `-3π` 折到 `π`。`angleDelta` 从 `170°` 到 `-170°` 的差是 `20°` 对应的弧度，而不是绕远路的那一圈。
10. 上述函数在 Jest 里对固定输入重复运行，结果按二进制相等。测试不调用会分配的创建函数来做运算，只在用例开头创建缓冲。
