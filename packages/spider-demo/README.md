# 重岳 · 正面自然站姿

24 根骨骼、6 张透明分片、16 个关节控制，由仓库的 render-engine 完成加权蒙皮与 WebGL2 绘制。支持骨架叠加、视图缩放和平移、姿态重置和透明 PNG 导出。

从仓库根目录启动（需已构建 `packages/render-engine/dist`）：

```sh
PORT=5175 node packages/spider-demo/server.mjs
```

访问 http://127.0.0.1:5175/ 。

使用已安装 numpy、Pillow 的 Python 重新生成素材与网格：

```sh
python3 packages/spider-demo/build-chongyue-front.py
```

`assets/chongyue/front/` 保留原始参考图、肩部补图源、骨架层级、运行时骨架/网格/姿态数据和 6 张分片。肩部补图源是重新生成分片所需的输入，不随预览加载。生成脚本内保留分片隔离、蒙皮权重及胸腹主体保护校验。

肩点已向锁骨和袖口的连接处重新校准。肩头上缘平滑连接胸侧，下方上臂保持刚性旋转；衣服袖口绘制在完整肩头之前，遮住中性姿态下不可见的皮肤。新生成素材仅用于补齐遮挡区，保留原图可见的纹身和护甲，不再使用独立补缝网格或按开合切换补片。肩部局部加密到 10 像素网格，手臂开合范围仍为 ±20°。

胸腹中心不受肩膀影响，外侧衣料最多使用 7% 的肩骨权重，保留轻微随动。颈部的重叠网格继续采用共同权重及三角形划分。运行时仍为 24 根骨骼、6 张纹理、6 个网格和原有 16 个控制项，支持透明背景导出。
